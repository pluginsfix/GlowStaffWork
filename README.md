# GlowStaffWork

Плагин для управления рабочей сменой персонала на серверах Minecraft (Paper, Purpur, Folia) с отслеживанием статистики, интеграцией с LiteBans, выполнением настраиваемых команд и поддержкой PlaceholderAPI.

## Возможности

- Включение и завершение смены персонала (`/sw on`, `/sw off`).
- Автоматическое выполнение консольных команд при выходе на смену и завершении смены (с поддержкой плейсхолдеров).
- Детальный учёт времени: время текущей смены, отработанное за сегодня, общее отработанное время, количество смен.
- Интеграция с LiteBans: подсчёт выданных банов, мутов, киков и предупреждений (варнов).
- Просмотр статистики для себя и других игроков (`/sw info [ник]`).
- Уведомления и бродкасты для персонала.
- Встроенная база данных SQLite с пулом соединений HikariCP.
- Полная поддержка серверов Folia и Paper.
- Поддержка PlaceholderAPI.

## Команды

- `/sw on` — выйти на смену.
- `/sw off` — завершить смену.
- `/sw info` — посмотреть свою статистику работы и наказаний.
- `/sw info <ник>` — посмотреть статистику работы и наказаний указанного сотрудника.
- `/sw reload` — перезагрузить конфигурацию и сообщения.
- `/sw help` — список доступных команд.

## Права

- `glowstaffwork.use` — доступ к командам `/sw on`, `/sw off`, `/sw info`, `/sw help` (по умолчанию: `op`).
- `glowstaffwork.staff` — получение оповещений о начале и завершении смены сотрудниками (по умолчанию: `op`).
- `glowstaffwork.info.others` — просмотр статистики других игроков через `/sw info <ник>` (по умолчанию: `op`).
- `glowstaffwork.admin` — перезагрузка плагина через `/sw reload` (по умолчанию: `op`).

## Плейсхолдеры PlaceholderAPI

- `%glowstaffwork_status%` — статус сотрудника (`on` / `off`).
- `%glowstaffwork_status_formatted%` — форматированный статус (`На смене` / `Не на смене`).
- `%glowstaffwork_session_time%` — длительность текущей смены.
- `%glowstaffwork_today_time%` — отработанное время за сегодня.
- `%glowstaffwork_total_time%` — общее отработанное время.
- `%glowstaffwork_sessions%` — общее количество завершённых смен.
- `%glowstaffwork_bans%` — количество выданных банов (LiteBans).
- `%glowstaffwork_mutes%` — количество выданных мутов (LiteBans).
- `%glowstaffwork_kicks%` — количество выданных киков (LiteBans).
- `%glowstaffwork_warns%` — количество выданных предупреждений (LiteBans).
- `%glowstaffwork_punishments_total%` — общее количество всех выданных наказаний (LiteBans).
- `%glowstaffwork_last_seen%` — дата и время последней активности.
- `%glowstaffwork_active_count%` — количество сотрудников на смене в данный момент.
